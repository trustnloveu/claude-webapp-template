# 공통 원칙

> 대상: 사람

원본 규칙은 루트 `CLAUDE.md`의 "작업 방식"이며 모든 세션에 자동 적용됩니다.
이 파일은 Claude가 원칙을 어기는 것 같을 때 다시 붙여 넣기 위한 사본입니다. 규칙을 바꿀 때는 `CLAUDE.md`를 먼저 고치고 이 파일을 맞춥니다.

## 질문 우선 (원본 ㉛)
```text
요구사항이 불명확하거나 여러 가지로 해석될 수 있으면 임의로 판단하지 말고 먼저 질문해.
확정된 요구사항과 추정한 내용을 구분하고, 추정이 필요하면 선택지와 장단점을 제시해.
```

## 계획 먼저 (원본 ㉜)
```text
코드를 고치기 전에 다음 순서로 진행해.
1. 현재 상태 분석  2. 구현 목표  3. 수정할 파일 목록  4. 구현 계획  5. 영향 범위와 예상 문제
계획을 내가 승인하기 전에는 코드를 수정하지 마.
```
Claude Code의 계획 모드(Plan mode)를 써도 같습니다.

## 기존 코드 보호 (원본 ㉝)
```text
요청한 기능과 관련 없는 파일은 수정하지 마.
기존 기능 삭제, 기존 API 인터페이스 변경, 새 패키지 설치는 하기 전에 먼저 물어봐.
변경한 내용과 이유를 설명해.
```

## 자체 검증 (원본 ㉞)
```text
완료라고 보고하기 전에 빌드, 타입 검사, 린트, 테스트를 실제로 실행해.
실행한 검사와 실행하지 못한 검사를 구분해서 결과와 함께 보고해.
```
