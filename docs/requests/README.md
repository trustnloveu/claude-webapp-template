# 요청서

> 대상: 공용
> 작성: 총괄(메인 세션) · 확정: 사람

기능 하나, 수정 하나 같은 작은 요청을 정리해 두는 곳입니다. 프로젝트 전체 요구사항은 [../planning/requirements.md](../planning/requirements.md)에 둡니다.
`/refine`으로 정리한 요청서를 사람이 원할 때 저장합니다. 파일 이름: `YYYY-MM-DD-<짧은-이름>.md`

## 양식

```markdown
# <요청 제목>

- 날짜: <YYYY-MM-DD>
- 요청자: <사람>
- 관련: <기능 ID, 화면 ID, 요구 번호>

## 원문
<받은 그대로>

## 요청서
[단계] [목표] [배경] [범위] [제외] [완료 조건] [제약] [참고] [모르는 것]

## 작업 계획
<`/plan-work` 계획서. 계획 승인 후 붙임>

## 결과
<결과 승인 날짜, PR 링크>
```
