## 환경
| 환경 | 브랜치 | URL | 배포 방식 |
|---|---|---|---|
| 로컬 | `feat/*` 등 작업 브랜치 | http://localhost:<포트> | 없음 (내 PC에서 실행, 로컬 `.env`) |
| 개발 | `dev` (기본 브랜치) | <URL> | `dev` 병합 시 자동 |
| 운영 | `prd` | <URL> | `dev` → `prd` 릴리스 PR 병합 시, 수동 승인. 병합 후 태그 `vX.Y.Z` |

브랜치 흐름: `feat/*` → PR → `dev` → 릴리스 PR → `prd` (+ 태그). `dev`·`prd`는 GitHub ruleset, 위험 명령 훅, settings.json deny로 보호한다.
